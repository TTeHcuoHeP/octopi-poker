# Octopi Poker — homepage prototype

React + TypeScript + Vite. Семь секций, плавающая навигация, мобильное меню, две темы, FAQ и демонстрационный CTA.

## Локальный запуск

Требуется Node.js 22.12+ (или совместимая более новая версия).

```sh
npm install
npm run dev
```

Production-проверка: `npm run build`, затем `npm run preview`.

## Vercel

Импортировать репозиторий `TTeHcuoHeP/octopi-poker`, выбрать Vite, корневую папку `./`.
Команда сборки: `npm run build`; выходная папка: `dist`. Переменные окружения пока не требуются.

## Статус прототипа

Регистрация не подключена: CTA открывает честное демонстрационное окно и генерирует локальное событие `octopi:cta` с placement и query. Данные никуда не отправляются. При подключении регистрации сохранить UTM/affiliate-параметры и один адрес назначения.

Реальные скриншоты, логотип, портреты и согласованные отзывы ожидаются. Используются явно обозначенные заглушки. Число 18,000+ взято из брифа и требует подтверждения. Цвета — предварительные, не официальные токены. Google Fonts загружаются по сети.

`moodboard/`, `design-work/`, DOCX и исследовательские скриншоты остаются локально и исключены из Git, чтобы не публиковать исходные материалы заказчика. Сгенерированные визуальные концепты сохраняем в `design-work/concepts/`.

## Основные файлы

- `src/main.tsx` — содержимое и взаимодействия.
- `src/styles.css` — адаптивная сетка, темы и стили.
- `vercel.json` — параметры сборки для Vercel.

Прототип помечен `noindex`; это не контроль доступа. Для закрытой демонстрации используйте защиту deployment в Vercel.
